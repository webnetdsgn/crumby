# Подключение Gemini бесплатно: пошагово

Всё ниже работает без оплаты и без установки программ на компьютер. Нужны: Google-аккаунт, почта для Cloudflare, телефон.

Что проверено, а что нет: сервер (`worker/index.js`) и приложение я прогнал на имитации Gemini. На настоящем ключе и в самом Cloudflare не запускал, поэтому названия кнопок в панелях могут немного отличаться.

## Что вы получите

Один адрес вида `https://crumb.<имя>.workers.dev`. Он отдаёт приложение и сам обращается к Gemini. Ключ Gemini лежит на сервере и в приложении не виден.

## Шаг 1. Ключ Gemini (без карты)

1. Откройте https://aistudio.google.com/apikey и войдите в Google-аккаунт.
2. Нажмите **Create API key**, выберите новый проект, скопируйте ключ (начинается с `AIza`).
3. **Платёжный аккаунт не привязывайте.** Пока он не привязан, вы на бесплатном уровне и списаний быть не может.

Важно:

- Подписка Google AI Pro ключа не заменяет: API живёт отдельно от неё.
- У бесплатного уровня есть лимиты запросов в минуту и в день на проект. Точные цифры: https://aistudio.google.com/rate-limit. При лимите приложение покажет «Слишком много запросов», подождите.
- На бесплатном уровне Google может использовать присланные данные для улучшения своих продуктов. Поэтому только ваши личные тесты, посторонних не приглашайте.

## Шаг 2. Cloudflare (бесплатный план)

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (почта и пароль, потом подтвердите почту). Карта на бесплатном плане обычно не нужна, но я этого в документации не подтвердил.
2. Слева выберите **Workers & Pages** → **Create application**, затем импорт из **GitHub**.
3. Разрешите Cloudflare доступ к GitHub (достаточно выбрать только репозиторий `crumb`) и выберите `webnetdsgn/crumb`.
4. Имя проекта оставьте **crumb**. Оно должно совпадать с `name` в `wrangler.toml`, иначе сборка упадёт.
5. Команду сборки (build) оставьте пустой, команду деплоя (deploy) не меняйте (`npx wrangler deploy`). Нажмите **Save and Deploy**.
6. Через 1–2 минуты появится адрес `https://crumb.<имя>.workers.dev`.

## Шаг 3. Секрет с ключом

Откройте **Workers & Pages → crumb → Settings → Variables and Secrets → Add** и добавьте значение типа **Secret**:

| Имя | Значение |
|---|---|
| `GEMINI_API_KEY` | ключ из шага 1 |

Необязательно, для владельца и друзей: `APP_PASSCODE` (ваш личный код) и `APP_PASSCODES` (коды друзей через запятую). Они дают синхронизацию между устройствами и повышенный лимит, но приложение работает и без них. Подробности: [LAUNCH.md](LAUNCH.md).

Нажмите Deploy, если панель предложит применить изменения.

Проверка: откройте `https://crumb.<имя>.workers.dev/api/health`. Должно быть `"ai":true`.

## Шаг 4. Телефон

1. Откройте адрес `workers.dev` в Safari.
2. Нажмите **+** → **Описать** → «кофе с двумя ложками сахара» → **Оценить**. Ответ придёт сразу, ничего вводить не нужно.
3. **Поделиться** → **На экран «Домой»** → **Добавить**.

## Если не работает

| Что видно | Причина и что делать |
|---|---|
| ИИ не отвечает и в Профиле нет кнопки «Проверить ИИ» | Сервер не вернул `ai:true`. Проверьте секрет `GEMINI_API_KEY` и адрес `/api/health` |
| «Неверный или не введён код доступа» | Открытый доступ выключен (`OPEN_ACCESS=off`) или код введён неверно |
| «Слишком много запросов» | Лимит бесплатного Gemini. Подождите минуту или до завтра |
| «Сбой связи» | Ключ неверный или модель недоступна. Добавьте переменную `GEMINI_MODEL` со значением `gemini-3.5-flash-lite` |
| Сборка в Cloudflare падает | Имя проекта не `crumb`, или не выбран репозиторий |

## Безопасность

- Ключ хранится только как секрет Cloudflare. В репозитории и в чате его быть не должно.
- Код доступа защищает вашу квоту. Не публикуйте ни адрес, ни код. Сменить код можно, изменив секрет.
- Пока всё бесплатно: Cloudflare Workers Free даёт 100 000 запросов в день, статические файлы бесплатны. Платить придётся, когда придут реальные пользователи и вы включите платный уровень Gemini (в нём Google не использует данные для обучения).
