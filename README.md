# Crumb

Приложение для подсчёта калорий с ИИ. Главная идея: считать всё, даже крошки. Мелкие перекусы незаметно решают результат, поэтому запись перекуса занимает одно касание.

*Crumb is an AI calorie tracker built around tiny snacks. Mobile web app (PWA), Russian and English.*

## Статус

Концепт. Работает как веб-страница для телефона (Safari, «На экран Домой»). Подключение Gemini бесплатно за четыре шага: [docs/SETUP-FREE.md](docs/SETUP-FREE.md). Внутри claude.ai ИИ отвечает Claude, на своём адресе Cloudflare отвечает Gemini.

## Что внутри

| Папка | Что это |
|---|---|
| `app/` | Рабочий прототип: анализ при регистрации, план на день, плитки (вариант D4), фото и текстовый ввод с ИИ, перекусы, вода, прогресс, строгий ИИ-коуч, русский и английский |
| `board/` | Доска идентичности: 12 названий с логотипами и 12 вариантов главного экрана |
| `worker/`, `wrangler.toml` | Серверная прослойка Cloudflare Worker: отдаёт `app/` и пересылает ИИ-запросы в Gemini, ключ только в секретах |
| `docs/` | [Пошаговая инструкция](docs/SETUP-FREE.md), [запуск для друзей: коды, уведомления, домен, нагрузка](docs/LAUNCH.md) и [устройство подключения Gemini](docs/GEMINI.md) |

Локальный запуск (без ИИ, ответы-примеры):

```bash
cd app && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Принципы продукта

- **Бесплатное работает по-настоящему.** Дневник, вода, план и быстрый ввод перекусов без ограничений. Платным становятся безлимит ИИ-фото, коуч и автопересчёт плана. Никакой стены подписки при входе.
- **Честность про точность.** ИИ оценивает, а не измеряет: по фото не видно масла и сахара. Поэтому приложение показывает уверенность, задаёт 1–2 вопроса о скрытом и подстраивается по тренду веса.
- **Строгий коуч.** Прямо и по делу, без утешений. Запрещено: стыдить за тело, предлагать голодание, калории ниже безопасного минимума.
- **Приватность.** Данные о здоровье только у пользователя, фото не хранятся, удаление аккаунта одной кнопкой.

## Дизайн

Оранжевая гамма Claude (`#D97757` холст, `#FAF9F5` карточки, `#141413` текст). Шрифты: Unbounded для заголовков и цифр, Onest для текста. Тёмная тема «Ночная» включается вручную и не следует за системной.

## Как вносить правки

Рабочий репозиторий: `webnetdsgn/crumby`. Cloudflare следит за веткой `main` и сам выкладывает каждое обновление (сборка занимает 1–2 минуты).

1. Правим файлы (приложение лежит в `app/`, серверная часть в `worker/`).
2. Отправляем в `main`.
3. Через 1–2 минуты обновлённая версия на адресе `workers.dev`. На телефоне достаточно закрыть и снова открыть приложение.

Секреты (`GEMINI_API_KEY`, а также необязательные `APP_PASSCODE`, `APP_PASSCODES`) меняются только в панели Cloudflare: Workers & Pages → crumby → Settings → Variables and secrets. В репозитории их нет и быть не должно.

Репозиторий `webnetdsgn/crumb` остался от первой версии и больше не используется.

Статус сборки каждого коммита виден на GitHub рядом с коммитом (проверка «Workers Builds: crumby»). Если она красная, лог лежит по ссылке из проверки в панели Cloudflare.
